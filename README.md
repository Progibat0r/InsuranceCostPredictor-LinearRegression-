# InsuranceCodePredictor
Linear Regression AI that attemps to predict insurance cost by some qualities
Это проект на Python, который позволяет предсказывать стоимость страховки через веб-сайт. Модель использует линейную регрессию и введенеык пользователем данные (возраст, пол, ИМТ, курение и т.д.).

Сайт оформлен в папке InsurancePrediction/, где лежит фронтенд и серверная часть.

Ссылка на репозиторий: https://github.com/Progibat0r/InsuranceCostPredictor-LinearRegression-


-------------Структура проекта--------------------------------------------------------------------------------------------------------

InsurancePrediction/ — веб-сайт проекта (HTML, CSS, JS и серверный код).

  /statis/ - хранит в себе сатические элементы, как картинки и CSS код
  /templates - хранит в себе html файл
  app.py - реализация модельки для работы на веб-сайте

insurance.csv — датасет с характеристиками клиентов и стоимостью страховки.

lr_model.pkl — обученная модель для предсказания.

train_model.py — скрипт для обучения модели заново.

predict_model.py — скрипт для запуска модели (можно использовать внутри сайта).

lr_manual_dataset.py — пример работы с ручными данными.



--------------Как запустить сайт---------------------------------------------------------------------------------------------------------

-Клонировать репозиторий:
git clone https://github.com/Progibat0r/InsuranceCodePredictor

-Установить зависимости (например, Flask, pandas, scikit-learn):
pip install flask pandas scikit-learn

-Перейти в папку сайта и запустить сервер:
cd InsurancePrediction
python app.py  # или как у тебя называется главный скрипт

Открыть сайт в браузере:

http://127.0.0.1:5000


--------------Как пользоваться----------------------------------------------------------------------------------------------------------------

На сайте пользователь вводит данные (возраст, пол, ИМТ и другие характеристики), нажимает Submit, и получает предсказанную стоимость страховки.
